# One-minute chord changes

<span class="tag tag-guitar">Guitar</span>

After this lesson you can run the one-minute changes exercise on any two of your chords, count your clean changes, and use the count to see your progress from day to day.

Before this: [The E and A chords](04-chords-e-and-a.md), [The A minor and D chords](06-chords-a-minor-and-d.md), [Strumming with down strokes](08-strumming-down-strokes.md). You need: your guitar, a pick, a tuner and a timer (a phone timer is fine).

## The idea

### Sound first: how fast is a change?

Listen to this example. It changes chord every two beats at 60 bpm, which is one change every two seconds, or 30 changes in a minute. Your first goal is to be able to do a change at this speed, with every string ringing.

```abc
%%opts tab=guitar
X:1
M:4/4
L:1/4
Q:1/4=60
K:C clef=treble-8
"Em"[E,B,EGBe]2 "E"[E,B,E^GBe]2 | "Em"[E,B,EGBe]2 "E"[E,B,E^GBe]2 | "Am"[A,EAce]2 "E"[E,B,E^GBe]2 | "Am"[A,EAce]2 "E"[E,B,E^GBe]2 |]
```

A chord change is a movement your fingers learn through repetition, in the same way as a scale on the piano. The one-minute changes exercise puts a number on that learning, so you can see small improvements that you would not hear.

### The exercise

You need two chords. For example, E and A.

1. Put your fingers on the first chord and get the timer ready.
2. Start the timer for 60 seconds. Strum the chord once.
3. Change to the second chord and strum once. Change back and strum once. Keep going.
4. When the timer stops, count the changes. Count only the changes where every string rang cleanly. A change where a string was muted or buzzing doesn't count.
5. Write down the number. Rest your hands for 30 seconds, and repeat. Do three rounds per pair.

There is no metronome in this exercise. Go as fast as you can while still playing clean chords. If you rush and every strum is dull, your count will be low, so the exercise rewards clean changes and not speed alone.

Common mistake at step 4: counting messy changes. A sloppy change teaches a sloppy habit. If the sound is not clean, it doesn't count.

Stop if your hand or wrist hurts. One minute is short enough that you shouldn't feel pain; if you do, rest and check your fretting-hand pressure.

### Helping your fingers

Some changes are easier because a finger stays put.

| Pair | Fingers that stay | What to do |
|---|---|---|
| Em and E | Fingers 2 and 3 stay on strings 5 and 4 | Add and lift finger 1 on string 3 |
| Am and E | None, but the shape is the same | Slide the shape one string and keep its form |
| E and A | None | Lift the shape together and land it together |
| D and A | None | Move the three fingers as one group |
| Am and Em | None | Move the pair of fingers one string and add or lift finger 1 |

A finger that stays on the string through a change is the **anchor** finger. When there is an anchor, put your attention on the finger that moves. When there is no anchor, think of the next chord as a picture before you leave the old one: see the shape and then move your hand to it.

Three habits make changes faster.

1. Move all the fingers at the same moment, not one after another.
2. Lift the fingers only a little, and keep them near the strings.
3. Look at the next chord's first finger in your mind before you move.

### Your changes log

Copy this table into a notebook and fill it in. The target is the number of clean changes in a minute at which a pair is ready.

| Pair | Day 1 | Day 2 | Day 3 | Target |
|---|---|---|---|---|
| Em and E | | | | 30 |
| Am and E | | | | 20 |
| E and A | | | | 20 |
| D and A | | | | 20 |
| Am and Em | | | | 20 |
| Am and D | | | | 15 |

The targets are this book's goals, not standards from anywhere else. A score that is lower today than yesterday is normal on a tired day. Look at the trend over a week.

## Try it

Exercise 1. In the one-minute changes exercise, what does a change count as?

<details class="solution" markdown>
<summary>Answer</summary>

A change from one chord to the other, with a strum, where every string of the chord rings cleanly.

</details>

Exercise 2. The example at the top changes chords every two beats at 60 bpm. How many changes would that be in a minute, and how many strings must ring in an Am chord?

<details class="solution" markdown>
<summary>Answer</summary>

30 changes per minute (60 beats divided by 2 beats). Five strings must ring in Am (strings 5 to 1).

</details>

Exercise 3. Which two chords share two anchor fingers, and which strings do the fingers sit on?

<details class="solution" markdown>
<summary>Answer</summary>

Em and E. Fingers 2 and 3 stay on strings 5 and 4, both at fret 2.

</details>

### Practice routine (30 minutes)

| Minutes | What to do | Tempo | Listen for |
|---|---|---|---|
| 5 | Warm-up: strum each of Em, E, A, Am and D once, checking every string | Untimed | No muted strings |
| 15 | New skill: one-minute changes on three pairs from the log, three rounds each (60 seconds, then 30 seconds of rest), writing the scores down | Fastest clean speed | Clean chords, even when fast |
| 5 | Piano: Night Bridge or Slow Ferry, hands together | 50 bpm | No stops between positions |
| 5 | Reading: sight-read one line, using the scan | 50 bpm | The beat going through mistakes |

Repeat this routine on at least three days, using a different set of three pairs each day.

</div>

## Common mistakes

Moving one finger at a time. Move the whole shape together.

Lifting the fingers high off the strings. A small lift is faster than a big one.

Practising for too long. One-minute changes are an exercise, not a workout. Stop after the 15 minutes in the routine.

## Key terms

- **Chord change**: moving the fretting hand from one chord shape to another.
- **Anchor finger**: a finger that stays on its string through a chord change.
- **One-minute changes**: an exercise that counts clean chord changes between two chords in 60 seconds.
