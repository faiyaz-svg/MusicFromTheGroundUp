# Italian terms

Use this page to look up the Italian words printed on scores, from the first tempo marking to the roadmap words at the end of a piece. They cover the terms up to about RCM Theory Level 6.

The type column says what the term controls: tempo (speed), dynamics (volume), expression (mood or manner), articulation (how notes start and end), pedal (the piano pedals) and roadmap (the order in which you play the bars). A bpm range is the number of beats per minute for a quarter-note beat. Sources give slightly different ranges, so every range here is approximate; use it to set a metronome, then listen. Terms with an abbreviation list it in parentheses, since that is usually what is printed.

| Term | What it means | Type |
|---|---|---|
| a tempo | Go back to the speed before the last change (after rit. or rall.) | tempo |
| accelerando (accel.) | Gradually faster | tempo |
| adagio | Slow, at ease; about 66 to 76 bpm (approximate) | tempo |
| agitato | Restless, agitated | expression |
| al coda | To the coda: at the To Coda sign, jump to the coda | roadmap |
| al fine | To the end: play until the word Fine | roadmap |
| allargando | Getting broader and slower, often with more volume | tempo |
| allegretto | Moderately fast, a little slower than allegro; about 98 to 112 bpm (approximate) | tempo |
| allegro | Fast and lively; about 120 to 168 bpm (approximate) | tempo |
| andante | At a walking pace; about 76 to 108 bpm (approximate) | tempo |
| andantino | Close to andante, often a little lighter; about 80 to 110 bpm (approximate) | tempo |
| animato | Animated, with life | expression |
| cantabile | In a singing style | expression |
| con brio | With spirit | expression |
| con moto | With motion, a little faster | expression |
| con pedale | With the pedal: use the damper pedal | pedal |
| crescendo (cresc.) | Gradually louder | dynamics |
| da capo (D.C.) | From the head: go back to the beginning | roadmap |
| dal segno (D.S.) | From the sign: go back to the segno | roadmap |
| decrescendo (decresc.) | Gradually softer, the same as diminuendo | dynamics |
| diminuendo (dim.) | Gradually softer | dynamics |
| dolce | Sweetly, softly | expression |
| espressivo (espr.) | Expressively, with feeling | expression |
| fermata | Hold the note or rest longer than written; the player chooses how long | expression |
| fine | The end: where the piece stops after a D.C. or D.S. | roadmap |
| forte (f) | Loud | dynamics |
| fortepiano (fp) | Loud, then at once soft | dynamics |
| fortissimo (ff) | Very loud | dynamics |
| grazioso | Gracefully | expression |
| largo | Very slow and broad; about 40 to 60 bpm (approximate) | tempo |
| legato | Smooth, with no gap between notes; often marked with a slur | articulation |
| leggiero | Light and quick | expression |
| lento | Slow; about 52 to 68 bpm (approximate) | tempo |
| maestoso | Majestic, with dignity | expression |
| marcato | Marked: each note stressed and separated | articulation |
| meno | Less, as in meno mosso (less motion, slower) | expression |
| mezzo (mp, mf) | Half, used before piano or forte: mezzo piano (mp) is moderately soft, mezzo forte (mf) is moderately loud | dynamics |
| moderato | At a moderate speed; about 108 to 120 bpm (approximate) | tempo |
| molto | Very, much, as in molto rit. | expression |
| morendo | Dying away, slower and softer | dynamics |
| pianissimo (pp) | Very soft | dynamics |
| piano (p) | Soft | dynamics |
| più | More, as in più forte (louder) or più mosso (faster) | expression |
| poco | A little, as in poco rit. | expression |
| poco a poco | Little by little, as in poco a poco crescendo | expression |
| prestissimo | As fast as possible; above about 200 bpm (approximate) | tempo |
| presto | Very fast; about 168 to 200 bpm (approximate) | tempo |
| rallentando (rall.) | Gradually slower | tempo |
| ritardando (rit.) | Gradually slower | tempo |
| rubato | Stolen time: bend the tempo for expression, speeding up and slowing down slightly | tempo |
| sempre | Always, as in sempre staccato | expression |
| senza pedale | Without the pedal | pedal |
| sforzando (sfz) | A sudden strong accent on one note or chord | dynamics |
| simile | In the same way: keep using the pattern or articulation shown before | expression |
| sostenuto | Sustained, held out to full length | articulation |
| staccato | Short and detached; marked with a dot above or below the note | articulation |
| stringendo | Pressing forward, gradually faster | tempo |
| subito | Suddenly, as in subito piano (sudden soft) | expression |
| tempo primo (Tempo I) | Return to the first tempo of the piece | tempo |
| tenuto | Held for its full value, often with a slight lean | articulation |
| tranquillo | Calm | expression |
| tre corde | Three strings: release the left pedal after una corda | pedal |
| una corda | One string: press the left pedal for a softer, thinner tone | pedal |
| vivace | Lively and fast; about 140 to 176 bpm (approximate) | tempo |
